# DevOps Git Version Control Project

## Project Overview
This project demonstrates Git and GitHub version control practices as part of the DevOps Internship Task 4.

## Objectives
- Understand Git repository management.
- Implement branching strategies.
- Practice commits and pull requests.
- Resolve merge conflicts.
- Manage project versions using Git tags.

## Tools Used
- Git
- GitHub
- Windows PowerShell
- Visual Studio Code

## Branching Strategy
- main – Stable project branch.
- dev – Development branch.
- feature – Feature development branch.

## Tasks Completed
1. Initialized a Git repository.
2. Created a GitHub repository.
3. Pushed project files to GitHub.
4. Created main, dev and feature branches.
5. Created commits with meaningful messages.
6. Created and merged Pull Requests.
7. Practised merge conflict resolution.
8. Created Git tags.
9. Configured .gitignore.
